# Stock Screener

This project is built on top of the [Devias Material Kit React](https://github.com/devias-io/material-kit-react) template to provide a modern UI for screening stocks.

## Getting Started

1. Ensure you have a current LTS release of Node.js installed.
2. Install dependencies with your preferred package manager (pnpm recommended):
   ```bash
   pnpm install
   # or
   npm install
   ```
3. Start the development server:
   ```bash
   pnpm dev
   # or
   npm run dev
   ```
4. Open your browser to http://localhost:3000.

## Available Scripts

- `pnpm dev` / `npm run dev` – run the development server.
- `pnpm build` / `npm run build` – create a production build.
- `pnpm start` / `npm run start` – run the production build locally.
- `pnpm lint` / `npm run lint` – lint the project source.
